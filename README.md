# Red Horizon

![screenshot](screen.png)

## Управление

| Клавиша | Действие |
|---------|----------|
| W / ↑ | Движение вперёд |
| S / ↓ | Движение назад |
| A / ← | Движение влево |
| D / → | Движение вправо |
| Shift | Ускорение (x1.5) |
| F | Вкл/выкл фонарик |
| Esc | Выход |

## Создание карты

Каждый уровень хранится в папке `map/level_N/`:

```
map/level_1/
  map.txt      — тайл-карта стен и полов
  enemy.txt    — враги, бонусы, старт игрока
  decor.txt    — объекты декора и двери
```

### map.txt — Символы

| Символ | Описание |
|--------|----------|
| `&` | Стена (кирпич) |
| `@` | Стена (зелёная) |
| `#` | Стена (белая) |
| `0` | Пол (доски) |
| `.` | Пустота (игнорируется) |

### enemy.txt — Символы

| Символ | Описание |
|--------|----------|
| `Z` | Зомби |
| `M` | Военный зомби |
| `F` | Быстрый зомobi |
| `H` | Аптечка |
| `K` | Ключ |
| `P` | Стартовая позиция игрока |

### decor.txt — Формат

```
obj <тип> <col> <row> <y> <rotation> <scale> <collision>
door <col> <row> <rotation> <locked> <exit>
```

Типы объектов: `sofa`, `lamp`, `blood`, `trash`, `box`
Двери: `locked=1` — заперта (нужен ключ), `exit=1` — выход на следующий уровень

## Сборка

```bash
make
```

Требования: [raylib](https://www.raylib.com/), g++, Linux (X11)

## Редактор уровней

3D-редактор для размещения объектов, дверей, врагов и бонусов на карте. Использует тот же шейдер и визуализацию, что и игра.

### Запуск

```bash
make editor            # собрать редактор
./editor <номер_уровня>   # запустить (по умолчанию уровень 1)
make run_editor LEVEL=1   # то же самое через make
```

### Управление камерой

| Клавиша | Действие |
|---------|----------|
| W / A / S / D | Перемещение камеры по горизонтали |
| Space | Лететь вверх |
| Shift (удержание) | Лететь вниз |
| Ctrl (удержание) | Ускорение камеры (x3) |
| Мышь | Обзор (вращение) |

### Палитра и размещение

| Клавиша | Действие |
|---------|----------|
| Tab | Переключение категории (DECOR / DOORS / ENEMIES / BONUSES / PLAYER) |
| 1–9 | Выбор объекта в текущей категории |
| E | Разместить объект под курсором |
| ЛКМ | Выбрать объект под перекрестием |
| ПКМ | Удалить объект под курсором |
| Колёсико мыши | Поворот объекта (+15°) |
| Shift + Колёсико | Смещение по Y |
| Ctrl + Колёсико | Масштаб (+0.1) |
| G | Вкл/выкл сетку |
| Enter | Сохранить файлы (decor.txt + enemy.txt) |

### Режим перемещения

При выделении объекта (ЛКМ) он начинает следовать за перекрестием:

| Клавиша | Действие |
|---------|----------|
| Колёсико мыши | Поворот |
| Shift + Колёсико | Высота (Y) |
| Ctrl + Колёсико | Масштаб |
| Enter | Подтвердить позицию |
| Esc | Отмена выделения |
| Delete / Backspace | Удалить выделенный объект |

### Категории объектов

**DECOR** — статичные объекты сцен:

| # | Объект | Модель | Коллизия |
|---|--------|--------|----------|
| 1 | sofa | models/sofa.obj | да |
| 2 | lamp | models/lamp.obj | нет |
| 3 | blood | models/blood.obj | нет |
| 4 | trash | models/trash.obj | да |
| 5 | box | куб (генерируется) | да |

**DOORS** — двери:

| # | Тип | Цвет в редакторе |
|---|-----|-------------------|
| 1 | Обычная дверь | синий |
| 2 | Запертая (нужен ключ) | красный |
| 3 | Выход ( переход на следующий уровень) | зелёный |

**ENEMIES** — враги:

| # | Тип | Символ в enemy.txt | Цвет |
|---|-----|---------------------|------|
| 1 | Зомби | Z | красный |
| 2 | Военный зомби | M | серый |
| 3 | Быстрый зомби | F | оранжевый |

**BONUSES** — бонусы:

| # | Тип | Символ в enemy.txt | Цвет |
|---|-----|---------------------|------|
| 1 | Аптечка | H | жёлтый |
| 2 | Ключ | K | золотой |

**PLAYER** — стартовая позиция игрока:

| # | Тип | Символ | Цвет |
|---|-----|--------|------|
| 1 | Игрок | P | зелёный |

### Сохраняемые файлы

При нажатии **Enter** (или при закрытии окна) редактор записывает:

- `map/level_N/decor.txt` — объекты и двери
- `map/level_N/enemy.txt` — враги, бонусы и старт игрока

### Формат decor.txt

```
obj <тип> <col> <row> <y> <rotation> <scale> <collision>
door <col> <row> <rotation> <locked> <exit>
```

Примеры:
```
obj sofa 3.5 3.5 3.5 0 4.0 1
obj lamp 5.0 5.0 19.0 0 0.5 0
door 0.5 17.5 90 1 1
```

### Формат enemy.txt

Символьная сетка (пробелы между символами), совпадающая по размеру с map.txt:

```
. . . . .
Z . . . .
. . H . .
. . . . P
```

Символы: `Z` (зомби), `M` (военный), `F` (быстрый), `H` (аптечка), `K` (ключ), `P` (старт игрока)
